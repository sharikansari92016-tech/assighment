# HTML & CSS Practical Assignments

This repository contains my HTML and CSS practical assignments, completed as part of my web development learning.

## 📚 About the Project

The project includes 45 practical assignments divided into 9 modules. These assignments cover basic HTML, CSS styling, layout design, Git, GitHub, and responsive web development.

## 🗂️ Modules

1. **Setup & Git** — Browser basics, terminal navigation, and GitHub repositories.
2. **HTML Basics** — Headings, paragraphs, and semantic HTML.
3. **Links, Images & Lists** — Navigation links, images, and lists.
4. **Forms, Tables & Metadata** — Registration forms, tables, and metadata.
5. **CSS Fundamentals** — Selectors, fonts, colours, and CSS variables.
6. **Box Model & Positioning** — Cards, spacing, overflow, and positioning.
7. **Flexbox** — Responsive navigation bars and layouts.
8. **CSS Grid** — Photo galleries, product grids, and dashboards.
9. **Responsive Design & Integration** — Media queries and responsive landing pages.

## 🛠️ Technologies & Tools

- HTML5
- CSS3
- Visual Studio Code
- Git and GitHub
- Live Server

## 🚀 How to Use

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open an HTML file in your browser or use the Live Server extension.
4. Explore the assignments module by module.

## 🎯 Learning Goals

- Understand HTML structure and semantic elements.
- Learn CSS styling and layout techniques.
- Practise Flexbox, CSS Grid, and responsive design.
- Develop practical experience with Git and GitHub.
